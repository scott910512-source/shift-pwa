# 4조 2교대 근무표 (PWA)

공장 4조 2교대(3일 근무 · 3일 휴무, 12일 주기) 근무표.
빌드 도구 없는 정적 파일(HTML/CSS/바닐라 JS)이며, 홈화면 설치와 완전 오프라인 동작을 지원합니다.

## 화면 (하단 탭 4개)
1. **홈** — 오늘 주간·야간 카드(조 / 교대조장 / 공장별 근무자 이름) → 휴무조 한 줄 → 월간 달력
2. **달력** — 날짜마다 `주 X` `야 Y` 를 함께 표시. 날짜를 누르면 바텀 시트로 그날 명단
3. **조 정보** — A~D 조 구성원 조회
4. **설정** — 근무조 구성 편집 / 근무 패턴 / 앱 설정(테마) / 백업·복원

## 근무 패턴
- 앵커: `2026-08-27` = 사이클 0일차 (주간 D · 야간 B)
- 블록 순서: `D/B → C/A → B/D → A/C` (3일마다 전환, 12일 주기)
- 교대 시각: 주간 08:00–20:00 / 야간 20:00–08:00
- 모든 날짜·시간 계산은 **한국 표준시(Asia/Seoul) 고정** — 기기 시간대와 무관

## 명단 관리
앱 안 **설정 → 근무조 구성**에서 직접 편집합니다. 코드 수정이 필요 없습니다.

- 조(A~D)를 고르고 교대조장 1명 + 1·2·3공장 조원을 입력
- 공장별 인원은 0명부터 제한 없이 추가/삭제 가능 (인원수가 아니라 이름 배열로 저장)
- `저장`을 누르면 `localStorage` 에 기록되어 앱을 껐다 켜도 유지
- **설정 → 백업/복원** 에서 JSON 내보내기·복원·초기화

저장 형태:

```json
{ "crews": { "A": { "leader": "홍길동",
    "factories": { "1": ["김철수","이영희"], "2": [], "3": [] } } } }
```

기본 명단은 `app.js` 의 `seedCrews()` 에 있습니다. 저장된 값이 없을 때만 쓰입니다.

## 배포 (GitHub Pages)
1. `icons/` 에 아이콘 PNG 3개를 넣습니다 (`icons/README.md` 참고).
2. Settings → Pages → Source: `main` 브랜치 루트.
3. `https://<아이디>.github.io/<리포명>/` 으로 접속 후 홈화면에 추가.

모든 경로가 상대경로(`./`)라 서브경로 배포에서 그대로 동작합니다.
앱을 갱신할 때는 `sw.js` 의 `CACHE_VERSION` 값을 올리세요.

## 검증
앱을 열면 콘솔에 근무 패턴 검증 10건이 자동 출력됩니다 (앵커 이전 과거 날짜 포함).
콘솔에서 `SHIFT.runSelfTest()` 로 다시 실행할 수 있습니다.
