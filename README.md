# 4조 2교대 근무표 (PWA)

공장 4조 2교대(3일 근무 · 3일 휴무, 12일 주기) 근무표.
빌드 도구 없는 정적 파일(HTML/CSS/바닐라 JS)이며, 홈화면 설치와 완전 오프라인 동작을 지원합니다.

## 화면 (하단 탭 5개)
1. **근무표** — 상단 정보바(날짜·시계·현재 교대) → 오늘 주간/야간 카드 2장 → 휴무 조 → 달력(기본 2주, `전체 달력`로 한 달 전환). 날짜를 누르면 바텀 시트로 그날 명단
2. **교대 현황** — 오늘 A~D 조가 각각 주간/야간/휴무 중 무엇인지 + 조별 구성원
3. **조 설정** — 교대조장·공장별 조원 편집 후 저장
4. **공지사항** — `app.js` 의 `NOTICES` 에 넣고 배포하면 모두에게 보임
5. **설정** — 근무 패턴 / 앱 설정(테마) / 백업·복원

## 근무 패턴
- 앵커: `2026-08-27` = 사이클 0일차 (주간 D · 야간 B)
- 블록 순서: `D/B → C/A → B/D → A/C` (3일마다 전환, 12일 주기)
- 교대 시각: 주간 08:00–20:00 / 야간 20:00–08:00
- 모든 날짜·시간 계산은 **한국 표준시(Asia/Seoul) 고정** — 기기 시간대와 무관

## 상근 인원

교대를 돌지 않는 상근 인원은 `app.js` 의 `STAFF` 배열에 따로 둡니다.
**교대 현황** 탭 맨 아래에서 확인할 수 있고, A~D 조 명단과 섞이지 않습니다.
조 설정에서는 편집하지 않고 배포 값만 씁니다.

## 명단 관리
앱 안 **설정 → 근무조 구성**에서 직접 편집합니다. 코드 수정이 필요 없습니다.

- 조(A~D)를 고르고 교대조장 1명 + 1·2·3공장 조원을 입력
- 공장별 인원은 0명부터 제한 없이 추가/삭제 가능 (인원수가 아니라 이름 배열로 저장)
- `저장`을 누르면 `localStorage` 에 기록되어 앱을 껐다 켜도 유지
- **설정 → 백업/복원** 에서 JSON 내보내기·복원·초기화

저장 형태:

```json
{ "crews": { "A": { "leader": "홍길동",
    "factories": { "1": ["김철수","이영희"], "2": [], "3": [] } } } }
```

## 기본 명단 배포 (여러 사람이 같은 명단 보기)

`app.js` 의 `seedCrews()` 가 배포용 기본 명단입니다. 명단을 바꿔 배포하려면:

1. `seedCrews()` 의 이름을 수정
2. 바로 위 `SEED_VERSION` 을 1 올린다
3. `sw.js` 의 `CACHE_VERSION` 도 1 올린다
4. `main` 에 푸시

그러면 접속자별로 이렇게 동작합니다.

| 그 기기 상태 | 결과 |
|---|---|
| 설정에서 명단을 고친 적 없음 | 새 기본 명단이 **자동 반영** |
| 설정에서 직접 고친 적 있음 | 내 명단을 **유지**하고, 설정 → 근무조 구성에 "배포된 기본 명단 적용" 버튼 표시 |

직접 고친 기기는 설정 → 백업/복원 → `기본 명단으로 되돌리기` 로도 맞출 수 있습니다.
현재 상태는 설정 → 앱 설정의 `기본 명단 버전` / `현재 명단` 에서 확인합니다.

## 홈 화면 위젯 (아이폰)

`widget-loader.js` 를 Scriptable 앱에 한 번 붙여넣으면 홈/잠금 화면 위젯으로
오늘 근무조를 볼 수 있습니다. 설치 방법은 [WIDGET.md](WIDGET.md) 참고.

로더가 `widget.js` 와 `crew.json` 을 받아 쓰므로, 레이아웃이 바뀌든 명단이
바뀌든 **다시 붙여넣을 필요가 없습니다.**
`crew.json` 은 `node tools/sync-crew.js` 로 `app.js` 의 `seedCrews()` 에서
자동 생성합니다 — 손으로 고치지 마세요.

## 배포 (GitHub Pages)
1. `icons/` 에 아이콘 PNG 3개를 넣습니다 (`icons/README.md` 참고).
2. Settings → Pages → Source: `main` 브랜치 루트.
3. `https://<아이디>.github.io/<리포명>/` 으로 접속 후 홈화면에 추가.

모든 경로가 상대경로(`./`)라 서브경로 배포에서 그대로 동작합니다.
앱을 갱신할 때는 `sw.js` 의 `CACHE_VERSION` 값을 올리세요.

## 검증
앱을 열면 콘솔에 근무 패턴 검증 10건이 자동 출력됩니다 (앵커 이전 과거 날짜 포함).
콘솔에서 `SHIFT.runSelfTest()` 로 다시 실행할 수 있습니다.
