# 4조 2교대 근무표 (PWA)

공장 4조 2교대(3일 근무 · 3일 휴무, 12일 주기) 근무표.
빌드 도구 없는 정적 파일(HTML/CSS/바닐라 JS)이며, 홈화면 설치와 완전 오프라인 동작을 지원합니다.

## 화면 (하단 탭 5개)
1. **근무표** — 상단 정보바(날짜·시계·현재 교대) → 오늘 주간/야간 카드 2장 → 휴무 조 → 달력(기본 2주, `전체 달력`로 한 달 전환). 날짜를 누르면 바텀 시트로 그날 명단
2. **교대 현황** — 오늘 A~D 조가 각각 주간/야간/휴무 중 무엇인지 + 조별 구성원
3. **조 설정** — 교대조장·공장별 조원 편집 후 저장
4. **공지사항** — `app.js` 의 `NOTICES` 에 넣고 배포하면 모두에게 보임
5. **설정** — 근무 패턴 / 앱 설정(테마) / 백업·복원

## 근무 패턴
- 앵커: `2026-08-27` = 사이클 0일차 (주간 D · 야간 B)
- 블록 순서: `D/B → C/A → B/D → A/C` (3일마다 전환, 12일 주기)
- 교대 시각: 주간 08:00–20:00 / 야간 20:00–08:00
- 모든 날짜·시간 계산은 **한국 표준시(Asia/Seoul) 고정** — 기기 시간대와 무관

## 상근 인원

교대를 돌지 않는 상근 인원은 `app.js` 의 `STAFF` 배열에 따로 둡니다.
**교대 현황** 탭 맨 아래에서 확인할 수 있고, A~D 조 명단과 섞이지 않습니다.
조 설정에서는 편집하지 않고 배포 값만 씁니다.

## 명단 저장 형태

공장별 인원은 0명부터 제한 없이 추가/삭제할 수 있습니다 (인원수가 아니라 이름 배열로 저장).
받아온 서버 명단은 `localStorage` 에도 남겨, 다음에 오프라인이어도 같은 명단이 뜹니다.
**설정 → 백업/복원** 에서 JSON 내보내기·복원·초기화를 할 수 있습니다.

```json
{ "crews": { "A": { "leader": "홍길동",
    "factories": { "1": ["김철수","이영희"], "2": [], "3": [] } } } }
```

## 명단은 서버(crew.json) 하나가 원본

`crew.json` 이 **유일한 원본**입니다. 웹앱·아이폰 위젯·PC 바탕화면이 모두 같은 파일을 읽습니다.
관리자가 이 파일만 고쳐서 푸시하면 모든 기기에 반영됩니다.

```
crew.json ──┬── 웹앱 (app.js)
            ├── 아이폰 위젯 (widget.js)
            └── PC 바탕화면 (desktop/wallpaper.py)
```

### 명단을 바꾸는 방법

1. `app.js` 의 `seedCrews()` / `STAFF` 를 수정
2. `node tools/sync-crew.js` — `crew.json` 과 `desktop/wallpaper.py` 를 맞춘다
3. `main` 에 푸시 → 1~2분 뒤 모든 기기 반영

GitHub 웹에서 `crew.json` 을 직접 고쳐도 됩니다.

<https://github.com/scott910512-source/shift-pwa/edit/main/crew.json>

로그인만 돼 있으면 토큰 없이 바로 고칠 수 있습니다. 대신 JSON 문법이
틀리면 앱이 명단을 못 읽으니 쉼표·괄호를 조심하세요. 고친 뒤에는
작업 PC 에서 `node tools/sync-crew.js --from-json` 으로 내장본도 맞춰
두세요 (한 번도 서버에 붙어본 적 없는 기기 대비).

> 앱 안에서 고치는 것은 **그 기기에만** 적용됩니다. 앱이 서버에 쓰는
> 기능은 없습니다 — GitHub Pages 는 읽기 전용이고, 거기에 쓰려면
> 브라우저에 GitHub 자격증명을 두어야 해서 넣지 않았습니다.

`SEED_VERSION` 을 올리는 것은 **선택**입니다. 앱이 `crew.json` 의 내용 지문을 보기 때문에
버전을 안 올려도 이름이 한 글자만 바뀌면 모든 기기가 알아챕니다.
(`sw.js` 의 `CACHE_VERSION` 은 앱 코드 자체를 바꿀 때만 올립니다. `crew.json` 은
서비스워커에서 network-first 로 처리하므로 캐시 버전과 무관하게 항상 최신을 받습니다.)

### 두 방향이 부딪히지 않게

`tools/sync-crew.js` 는 `crew.json` 의 `seedVersion` 이 `app.js` 보다 높으면
**멈춥니다**. GitHub 웹에서 `crew.json` 만 고친 것을 옛 `app.js` 로
덮어쓰는 사고를 막기 위한 것입니다.

| 상황 | 명령 |
|---|---|
| `app.js` 에서 고쳤다 | `node tools/sync-crew.js` |
| `crew.json` 을 GitHub 웹에서 고쳤다 | `node tools/sync-crew.js --from-json` |

### 접속자 기기에서 일어나는 일

| 그 기기 상태 | 결과 |
|---|---|
| 조 설정에서 명단을 고친 적 없음 | 서버 명단이 **자동 반영** |
| 조 설정에서 직접 고친 적 있음 | 내 명단을 **유지**하고, 조 설정에 "배포된 기본 명단 적용" 버튼 표시 |

현재 상태는 **조 설정**(PIN 해제 후) 맨 위 `관리자 명단 (서버)` 칸, 또는
**설정 → 앱 정보**의 `관리자 명단` 줄에서 확인합니다.

| 표시 | 뜻 |
|---|---|
| `최신` | 방금 서버에서 받은 명단 |
| `저장본` | 서버에 연결하지 못해, 이 기기가 지난번에 받아둔 명단 |
| `내장` | 받아둔 것도 없어 앱에 내장된 명단 (첫 실행 + 오프라인) |

`서버에서 다시 받기` 를 누르면 즉시 다시 확인합니다.
명단을 받지 못해도 앱은 그대로 동작합니다 — 비행기 모드에서도 근무표가 나옵니다.

## 기기에서 직접 고치기 (PIN)

앱 안 **조 설정**은 PIN(초기 `0000`)을 넣어야 열립니다. 여기서 고친 명단은
**그 기기에만** 적용되고 다른 사람에게는 가지 않습니다. 모두에게 반영하려면
위의 관리자 절차로 `crew.json` 을 바꿔야 합니다.

- 조(A~D)를 고르고 교대조장 1명 + 1·2·3공장 조원을 입력
- 조원 순서도 바꿀 수 있고, **맨 위가 보드**입니다
- 직접 고친 기기는 조 설정 → `배포된 기본 명단 적용`, 또는
  설정 → 백업/복원 → `기본 명단으로 되돌리기` 로 서버 명단에 다시 맞출 수 있습니다

## PC 바탕화면 (Windows)

`desktop/` 의 `install.bat` 을 실행하면 오늘 근무표를 그린 이미지를 바탕화면으로
지정하고, 로그온 시 · 매일 08:00 / 20:00 에 자동으로 갱신합니다.
명단이 스크립트에 내장돼 있어 **인터넷 없이 동작**합니다.
[desktop/README.md](desktop/README.md) 참고.

## 홈 화면 위젯 (아이폰)

`widget-loader.js` 를 Scriptable 앱에 한 번 붙여넣으면 홈/잠금 화면 위젯으로
오늘 근무조를 볼 수 있습니다. 설치 방법은 [WIDGET.md](WIDGET.md) 참고.

로더가 `widget.js` 와 `crew.json` 을 받아 쓰므로, 레이아웃이 바뀌든 명단이
바뀌든 **다시 붙여넣을 필요가 없습니다.**
`crew.json` 은 `node tools/sync-crew.js` 로 `app.js` 의 `seedCrews()` 에서
자동 생성합니다 — 손으로 고치지 마세요.

## 배포 (GitHub Pages)
1. `icons/` 에 아이콘 PNG 3개를 넣습니다 (`icons/README.md` 참고).
2. Settings → Pages → Source: `main` 브랜치 루트.
3. `https://<아이디>.github.io/<리포명>/` 으로 접속 후 홈화면에 추가.

모든 경로가 상대경로(`./`)라 서브경로 배포에서 그대로 동작합니다.
앱을 갱신할 때는 `sw.js` 의 `CACHE_VERSION` 값을 올리세요.

## 검증
앱을 열면 콘솔에 근무 패턴 검증 10건이 자동 출력됩니다 (앵커 이전 과거 날짜 포함).
콘솔에서 `SHIFT.runSelfTest()` 로 다시 실행할 수 있습니다.
